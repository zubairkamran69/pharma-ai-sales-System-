# 7-Minute Hackathon Demo

1. Sign in as Pharma Company.
2. Show Command Center: product sales, doctors, medicine portfolio and open escalations.
3. Open Medicine Library → Add medicine → create a product. Refresh to show persistence.
4. Open Doctor Intelligence → show specialty-to-medicine matching.
5. Open AI Sales Agent → ask: “Tell me about Cardiovex 10.” Show Product Knowledge Agent.
6. Log in as Doctor. Show that this dashboard has its own sales/earnings and matched products.
7. Request a medicine from Medicine Hub. Show the personalized order in My Requests.
8. Ask AI: “Can this medicine be prescribed differently for a patient with renal impairment?” The Risk Agent creates a Medical Affairs ticket instead of answering.
9. Switch back to Pharma Company → Human Escalations → open/resolve the ticket.
10. Explain that the production upgrade is LLM + RAG + approved documents + real human chat, while safety-critical decisions remain human supervised.
